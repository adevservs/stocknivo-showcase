## What you can do

### Create business documents

Prepare the core documents used in everyday business workflows:

- Invoices
- Service invoices
- Quotes
- Purchase orders

### Use practical browser tools

Find document and utility tools in one place, including PDF tools, QR-code generation, barcode generation, and other focused utilities.

## Made for a broad audience

Stocknivo offers English, French, Spanish, and Arabic language experiences. The Arabic interface supports right-to-left reading direction.
